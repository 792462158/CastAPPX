屏幕录制预览

- 点击右侧“屏幕录制”，在系统弹窗中选择共享整个屏幕或单个应用并确认，采集画面会实时显示在黑色预览区域。
- 左侧按钮仅按关闭 → 前置 → 后置 → 关闭循环切换，右侧按钮独立开启或停止屏幕录制，无需摄像头权限。录屏时摄像头关闭；点击左侧按钮切换到前置摄像头会先停止录屏。
- 点击“停止录屏”或通知栏中的停止操作结束采集；系统撤销共享时也会关闭预览。重新开始需要再次授权。
- 当前仅显示采集画面，不录制音频，也不保存视频文件。共享整个屏幕并查看本应用时，预览会包含自身，产生递归画面。

构建验证：`./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug`。本次使用 Android
Studio 内置 JBR 完成验证。

Socket 画面接收

- 一台设备启动 Socket 服务器后会停止本地摄像头和录屏，禁用上方两个采集按钮，并进入“等待画面接收”。停止服务器后恢复按钮，画面保持关闭。
- 另一台设备通过局域网设备列表连接服务器，再开启/切换摄像头或屏幕录制，即可自动通过 UDP 发送画面。服务端在
  `preview_container` 中按原始比例显示，状态切为“正在接收画面”。连接前已开启的采集也会在连接后自动发送。
- TCP 保留文字聊天并协商画面会话；UDP 使用与服务端 TCP 相同的端口号。当前每次只接受一台设备。
- 画面为 JPEG，最长边 960 像素，最高约 8 帧/秒；分片上限 1200 字节，乱序重组，重复或不完整帧丢弃。无音频。
- 对端关闭采集或画面中断超过 2.5 秒会清空预览并回到等待状态；TCP 断开时立即清空。静止录屏画面会定期重发，以保留接收状态。
- 本次升级增加了 TCP 会话消息类型，两端均需安装新版。
